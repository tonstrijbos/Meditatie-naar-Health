# Meditatie Health

Eenvoudige Nederlandstalige Android-app die uitsluitend mindfulness-sessies naar Health Connect schrijft.

## Functies
- 5, 10, 15, 20 of 30 minuten
- vrije duur invoeren
- schrijft als Meditation naar Health Connect
- leest geen gezondheidsgegevens
- vraagt alleen WRITE_MINDFULNESS

## Bouwen
1. Open de map in Android Studio.
2. Laat Gradle synchroniseren.
3. Kies Build > Build APK(s).
4. Installeer de APK op Android 14+ / Galaxy S25.

Let op: Android Studio/Gradle kan nieuwere pluginversies voorstellen. Het project gebruikt Health Connect client 1.1.0.
